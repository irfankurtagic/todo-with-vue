# To-Do with Vue

A lightweight and responsive to-do application built with **Vue**.

A small project created to experiment with Vue.js and build a simple, functional task list without unnecessary complexity.

## 🔗 Live Demo

**[Try To-Do with Vue](https://irfankurtagic.github.io/todo-with-vue/)**


## 🌙 Theme
The website automatically follows the user's system preference for light or dark mode using CSS prefers-color-scheme.

## ✨ Features

* ➕ Add tasks
* ✅ Mark tasks as complete
* 🗑️ Remove tasks
* 📱 Responsive interface
* 🌙 Light/dark theme support
* ⚡ Lightweight and dependency-free


## 🛠️ Technologies

* **Vue**
* **JavaScript**
* **HTML5**
* **CSS3**

## 🚀 Running Locally

Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/irfankurtagic/todo-with-vue.git
cd todo-with-vue
```

No build tools or package installation are required.

## 💡 About

This project was built as a small hands-on experiment with **Vue**, focusing on reactive UI updates, event handling, and keeping the application simple and easy to understand.
